# Currículo Justo

Monta um currículo pelo celular e gera PDF com a impressão do navegador. Não pede foto, idade, estado civil, CPF nem endereço, e aceita nome social. Bicos, trabalho informal, cuidado e voluntariado entram como experiência.

- Rodar: `python -m http.server 8732` nesta pasta e abrir http://127.0.0.1:8732
- Testar: `npm test` ou `npm run cobertura` (requer Node 22+)

Os dados ficam no navegador. Só são guardados no aparelho se a pessoa marcar essa opção.
